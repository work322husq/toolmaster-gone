# toolmaster-gone

`gone.xml` – товари toolmaster.kiev.ua брендів ESCO (DeWALT, STANLEY, BLACK+DECKER, BOSTITCH, STIGA, Sequoia, EnerSol,
Solo, Mungo) і Кентавра, яких уже немає у фідах постачальника (щонайменше ~2 доби). Для них наявність = 0.

* Оновлюється щоночі (~07:10 за Києвом) після моніторингу фідів.
* `vendorCode` = «Код товару» (model) на сайті; `stock_quantity` = 0; ціни у файлі немає – ціну не чіпати.
* Імпортувати ПІСЛЯ основних імпортів ESCO і Кентавра: лише поле наявності, за model.
* Товар повернувся у фід – він зникає з цього файлу, наявність знову ставить основний імпорт.
